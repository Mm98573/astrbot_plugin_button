# astrbot_plugin_button

用于让QQOfficial(QQ官方机器人)生成按钮消息的插件

## 简介
本项目是从一个普通的DeepSeek对话里诞生的，对一个普通的DeepSeek对话

此项目目前很简陋，只有多按钮，提个[issue](https://github.com/Mm98573/astrbot_plugin_button/issues)助力项目吧

## 如何使用
直接叫Agent生成一个测试按钮，点击后Agent会回复你

## 功能特性
- 多按钮
- 简单易用

## 安装
```bash
git clone https://github.com/Mm98573/astrbot_plugin_button.git
mv astrbot_plugin_button AstrBot目录/data/plugins/
```
